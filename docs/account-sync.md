# 账号与同步

本文同时记录红果账号接入和项目自建同步原型。「我的 → 红果账号」连接红果官方登录与云端片单。自建同步原型通过构建参数 `hongguoSyncUrl` 或环境变量 `HG_SYNC_URL` 配置，格式为 HTTPS origin，例如 `https://sync.example.com`。

## 红果账号

手表端支持两种登录方式：

- “红果 App 扫码”从官方官网登录接口取得二维码，用户在红果免费短剧 App 的“扫一扫”中确认。跳转、Cookie 和账号资料都会校验官方 HTTPS 域名。
- “手机号登录”走红果 App 的 Passport 短信接口。手机号和验证码由用户手动输入；平台要求额外验证时，界面只提示用户到官方流程完成，不自动处理滑块或发送短信。

登录凭据和匿名设备注册结果使用 Android Keystore 加密保存在应用的 no-backup 目录。每个红果账号使用独立的本地 Room 库；未登录库只作为登录时的待合并来源，切换账号不会把上一个账号的记录带给下一个账号。登录后会把红果云端历史和收藏并入当前“库”，所以手表库和手机红果看到的是同一批记录。首次登录发现手表已有本地记录时，会先询问是否合并；合并会保留两边的收藏并按剧集去重，历史按更后集数优先（例如第 350 集会覆盖第 300 集），同集再按最近更新时间和播放位置处理。选择仅使用红果云端时，会用云端记录替换本机红果剧集记录。一项读取失败时，另一项仍可正常显示，失败项保留本次应用运行期间上一次读到的内容。

登录后的自动同步默认开启。前台恢复、手表播放进度、收藏和取消收藏都会触发红果云端读写；云端刷新会让手机端已取消的收藏从手表库移除，并保留尚未上传的手表新增收藏。云端读取失败不会清空本机记录。手动“同步本机历史和收藏”仍可用于重试或补发旧记录。播放中的进度更新会合并后提交，离开播放器时会立即提交。

每次写入后都会从云端回读确认。接口成功响应但回读未体现变更时，界面会显示未确认，保留可重试状态。自动同步设置及尚未确认的收藏变更保存在加密会话文件中；进度仍以本地库为准，网络恢复或应用重新启动后可重新合并。退出红果账号会停止自动同步并清除该账号的待发送操作，但本机记录和红果云端记录都不会被删除。红果凭据只用于红果账号，项目自建同步使用独立会话。

写入接口格式参照 `N3urda/hongguoTV` 的 `CloudAccount.kt`。请求形状和云端回读已用本地协议测试覆盖；仍需用用户的红果账号做一次实际云端往返测试，才能确认当前服务端版本接受并持久化写入。

## 自建同步原型

自建同步用于红果终端设备之间共享记录。正式版尚未提供配对入口，也没有预配置生产服务。原型会向项目服务申请一次性配对码，手机浏览器打开 `/pair?user_code=...` 后登录或注册并确认授权。手表兑换会话后，凭据使用 Android Keystore 加密保存在应用的 no-backup 目录。

首次登录会明确询问是否合并手表上的访客历史和收藏。

- “合并本机数据”会把访客记录分批发送到账号。服务端只填充账号中没有的记录，已有记录和已取消的收藏不会被访客数据覆盖。
- “仅使用账号数据”会保留访客库，当前账号从服务端快照开始。
- 选择会保存在当前账号的 Room 库中。网络中断后可以重试，重复导入由服务端去重。

退出登录会立即切回访客库。不同账号使用不同的 Room 文件和同步游标，账号之间不会共用播放历史或收藏。退出后待同步修改仍留在原账号，下次登录该账号会继续发送。

## 同步内容

客户端只发送和接收以下字段。

- 播放历史中的剧集、剧名、封面、来源、集标识、集号、续播位置、时长和更新时间。
- 收藏中的剧集、剧名、封面、来源、总集数和更新时间。
- 取消收藏、清空历史和批次游标。

设备设置、离线视频、播放地址、账号密码和诊断日志不在同步范围内。播放历史按最后一次有效操作合并，不能用进度或集号的最大值代替用户的回退或重看操作。清空历史会形成服务端可识别的版本，旧设备不会把已清空的进度复活。

## 服务端

`server/account-sync` 是一个标准库 WSGI 参考服务，包含一次性配对、账号注册登录、Keystore 会话兑换、SQLite 账号隔离、增量游标、导入去重、冲突回执和请求限额。它只应放在 HTTPS 反向代理后使用。命令行参考如下。

```text
python server/account-sync/app.py --database /path/account-sync.sqlite3 \
  --listen 127.0.0.1 --port 8765 --public-origin https://sync.example.com
```

参考服务只绑定回环地址，避免未经配置就暴露账号接口。生产环境需要由独立的 HTTPS 反向代理提供 `https://sync.example.com`，并把 `/v1/*` 和 `/pair` 转发到该进程。不要把 SQLite 文件、会话令牌或调试日志放进公共目录。

Android 本地验证可以先跑服务端测试。

```text
python server/account-sync/test_app.py
```

客户端配置后运行协议和应用测试。

```text
set HG_SYNC_URL=https://sync.example.com
gradlew.bat :app:testDebugUnitTest
```

当前工作区完成了自建原型的代码、协议和测试验证。参考服务供本机验证使用。
