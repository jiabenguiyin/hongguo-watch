# 实机兼容性与诊断

## 测试矩阵

请优先测试最新 GitHub Release，记录设备型号、Android 版本、ABI、屏幕、内核与解码模式。不要仅凭模拟器或构建成功认定实机兼容。

| 项目 | 验收 |
| --- | --- |
| 首页、搜索、榜单 | 封面可显示，滚动加载稳定 |
| 播放 | 有声有画，实际首帧可见 |
| 解码兼容 | 对比系统内核与兼容软解的首帧、流畅度及画质（须保留 IJK/FFmpeg 软解路径） |
| 切集与续播 | 进度正确、无跨集错写 |
| 画面比例与旋转 | 等比、无拉伸，旋转后继续播放 |
| 锁定与手势 | 隐藏控件、不误触、可以解锁 |
| 库（收藏·历史） | 底栏「库」内分段切换无串页，重启数据仍在 |
| 安装升级 | 同签名覆盖安装，不清除应用数据 |
| 低内存设备 | 连播、退后台/返回无异常，记录卡顿与发热 |
| 息屏续播 | 默认熄屏即暂停；开启「息屏续听」后熄屏仍出声、返回键停止；记录耗电 |

## 诊断与隐私

诊断包括设备型号、系统信息、ABI、屏幕、解码能力、所选编码与画质、首帧时间及部分播放日志。播放失败时这些信息留在本机。只有点击「设置 → 上传诊断日志」才会发送，上传成功后可复制链接。

默认按序尝试公开粘贴服务（paste.rs → paste.gg → dpaste → uguu.se → tmpfiles.org）；构建时设置 `HG_DIAG_UPLOAD_URL` 可指向自定义服务。公共粘贴链接可能被持有链接的人访问，服务保存策略由服务方决定。不要将其视为私密存储。

提交公开 Issue 前请检查报告内容，仅分享必要的诊断字段，去除账号、Cookie、Token、完整媒体地址、私人网络信息等。
