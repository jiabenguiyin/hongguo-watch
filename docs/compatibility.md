# 实机兼容性与诊断

## 测试矩阵

请优先测试最新 GitHub Release，记录设备型号、Android 版本、ABI、屏幕、内核与解码模式。不要仅凭模拟器或构建成功认定实机兼容。

| 项目 | 验收 |
| --- | --- |
| 首页、搜索、榜单 | 封面可显示，滚动加载稳定 |
| 播放 | 有声有画，实际首帧可见 |
| 本地 H.264 / HEVC 自检 | 分别记录 360p、480p 的结果 |
| 切集与续播 | 进度正确、无跨集错写 |
| 画面比例与旋转 | 等比、无拉伸，旋转后继续播放 |
| 锁定与手势 | 隐藏控件、不误触、可以解锁 |
| 库（收藏·历史） | 底栏「库」内分段切换无串页，重启数据仍在 |
| 安装升级 | 同签名覆盖安装，不清除应用数据 |
| 低内存设备 | 连播、退后台/返回无异常，记录卡顿与发热 |

## 诊断与隐私

当前版本的诊断功能会收集设备型号、系统信息、ABI、屏幕、解码能力、所选编码/画质、首帧及部分播放日志。设置中可手动上传；部分播放失败也会自动尝试上传。

默认上传目的地为 paste.rs，失败可能使用 0x0.st；构建时设置 `HG_DIAG_UPLOAD_URL` 可指向自定义服务。公共粘贴链接可能被持有链接的人访问，服务保存策略由服务方决定。不要将其视为私密存储。

提交公开 Issue 前请检查报告内容，仅分享必要的诊断字段，去除账号、Cookie、Token、完整媒体地址、私人网络信息等。维护者应尽快提供上传确认、可关闭的自动上传、脱敏预览与受控端点，并明确告知保存与删除规则；这些是后续改进事项，不代表当前版本已经实现。
