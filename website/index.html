安卓手表 APK 安装

从项目最新发布页选择支持设备系统 ABI 的安装包：arm64-v8a（64 位 ARM）或 armeabi-v7a（32 位 ARM）。只需安装一个 APK。

开启未知来源安装权限后安装。同证书版本通常可覆盖升级；卸载会清除本地数据。当前测试签名私钥公开，请勿安装未知来源的修改包。

常见问题

哪些手表可以安装红果终端？

能够侧载 APK、运行 Android 7.0+ 的 ARM 安卓设备。并非所有封闭式手表或 Wear OS 设备都保证可用。

有声无画怎么办？

设置中尝试兼容软解及较低画质，记录设备信息后反馈。

如何更新红果终端？

通过应用内检查更新或本项目 GitHub Releases 获取新版本。目前下载依赖 GitHub，尚未提供已验证的国内镜像。

哪里可以反馈问题？

提交 Issue，或在应用设置查看项目交流群。公开日志前请脱敏。
